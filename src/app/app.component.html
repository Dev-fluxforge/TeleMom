Pillar 02

Daily Checkup & 3 Triage Paths

Daily SMS triage split into Path A (Safe/0), Path B (Moderate/3-4 alerting only the ward), and Path C (Immediate Emergency/1-2 or Beep alerting Ward, Companion, and Family).

Path A: Safe (0) → Reassurance
Path B: Headache/Fever (3-4) → Ward
Path C: Bleeding/Pain (1-2) → 3-Way

Autonomous escalation when checkups are ignored (Stage 1 reminder SMS, Stage 2 ward alert, Stage 3 full emergency broadcast).

Stage 1: Follow-up reminder to mother
Stage 2: Alert to ward phone to call
Stage 3: Full emergency broadcast
